# 连页：当前实现与验收

## 当前实现

- Android 10+：自动模式在 Android 10 使用系统屏幕捕获授权与前台服务，Android 11+ 使用无障碍截图能力；手动模式使用系统屏幕捕获授权，不要求无障碍。
- 首页直接切换自动滚动与自己滑动，两种模式统一悬浮控件；手动滑动指引持续显示，未能拼接时有恢复提示。
- 帮助自动识别主流厂商系统，结合真实权限/服务状态显示设置路径；关于精简为品牌、版本、本机处理说明和更新入口。
- 暖白、墨黑、陶橙体系，桌面图标与首页、关于统一为取景框和超出一屏的长页标记；支持中英文、明暗与大字体。
- 自动滚动与重叠匹配、条带瓦片存储、手动结束与中断后有效内容保留。
- 一个持久草稿：图像、裁剪、撤销重做、查看位置和保存状态；已提交检查点恢复。已保存截图不再提示继续编辑。
- 视口瓦片预览、缩放和快速定位；逐行 PNG 导出，30,000px 精确行分段或整张输出。
- 保存到相册、全部分图分享、私有分享缓存、导出失败清理及操作反馈。
- 工程与品牌统一为连页 / Lianye，正式包 `org.lianye`、调试包 `org.lianye.debug`；`v0.1.0` 的版本内容见根目录更新记录，正式发布状态以 GitHub Releases 为准。

这些条目说明代码中已提供的能力，不替代实机验收或正式发行记录。

## 已完成的本次验收（2026-10-03）

96 项 JVM 测试及华为 STK-AL00 / Android 10 上的 6 项仪器测试通过；Debug、签名 Release 构建成功，Lint 无错误（54 项警告）。真实系统测试覆盖跨瓦片裁剪遮盖、30,000px 分段边界、相册事务、多图 FileProvider 分享、编辑与页面重建、深色与大字体。

手动生成内容页面连续 28 段截取为 1080×21076 PNG，首尾及控件避让通过检查；手动结束保留 1080×7110 部分结果。保存、打开系统相册、取消分享保留草稿、权限说明及应用内停用服务已确认。测试结束后临时服务与屏幕捕获会话关闭，原正式版和原有图片保留。

详细命令、证书校验、证据位置及测试边界见 [实施记录](superpowers/plans/2026-10-02-product-redesign.md)。

## 发布前验收

1. 授权：Android 10 捕获授权、取消、失效；无障碍未开启、受限设置、状态未知、服务被系统关闭；检查实际下一步提示。
2. 截图：连续页面、动态画面、触底、手动结束、存储不足、中断；确认可用内容保留，侧边控件不污染成品。
3. 草稿：旋转、切换应用、系统分享、进程重建；确认图像、编辑和查看位置恢复。未保存草稿开始新任务需明确处理。
4. 导出：裁剪与遮盖像素一致；30,000px 边界、跨瓦片分段、所有分享 URI 和顺序；写入失败撤回新文件，取消分享保留草稿。
5. 视觉与访问性：浅深色、中文英文、小屏、大字体、横屏、折叠屏；检查文字截断、触摸区域、TalkBack、状态栏与控件对比度。
6. 工程：单元测试、Lint、网络依赖守卫、Debug 构建和签名 Release 构建。检查不同设备的耗时、内存和成品完整性，记录测量条件。
