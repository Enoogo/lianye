# 连页：直接可见的截图入口

用户本轮明确纠正两点：控制方式不应交给用户选择，自动/手动入口不应藏在帮助的二级菜单。此修订覆盖此前通知栏控制兜底和帮助内模式选择；不再追加方案选择或设计审批。

- 首页主动作上方直接显示「自动滚动 / 自己滑动」。沿用上次选择，切换只改变下一次截图方式，不开始采集、不丢失当前草稿。截图、导出或权限准备正在执行时锁定；未开始的手动准备可安全取消后切换。
- 两种方式都在目标页面使用同一个悬浮球。手动提示继续使用已确认的首次完整提示、后续淡化路线，不增加控制方式选项。
- 准备页只解释当前缺少的能力，并提供一个前往设置或继续授权按钮。手动先检查悬浮窗，再请求本次屏幕捕获；授权返回后延续原任务。拒绝授权留在应用，不请求通知权限、不静默切换控制方式。
- 通知只保留系统必需的捕获状态，不提供另一套开始/结束入口。手动继续不要求无障碍。
- 帮助展示当前方式的操作说明和相关系统路径；删除模式选择、重复开始、切换自动设置等任务入口。厂商适配和高级排障保留按需展开。

验收：首页两种方式直接可见且可切换，选中状态可访问；准备页各只有一个行动按钮；手动首次进入先引导悬浮窗、返回后请求投屏；帮助不再重复任务入口；已有草稿与活动会话保持保护；浅色、深色、英文大字号可达。检查最终实机截图，不只检查 Compose 函数。
