# 连页：实机 UI 精修

用户查看实际手机后指出界面粗糙，并授权打磨整个 UI。沿用已确认品牌、暖纸/石墨/橘色、V5 交互和简单够用原则。本轮修正原生视觉实现，不重新选择名称、Logo 或增加功能。

实机证据位于 `build/lianye-native-qa/ui-review-{home,preview,current}.png`。手机 font_scale=1.0，1080×2340 / 480dpi；问题来自默认中文粗字重、各处独立控件默认样式、整图适高缩略图和弹窗 FlowRow 换行。

统一规则：常用文字 14–15sp / 20–23sp 行高，标题 20–28sp，品牌 18sp；正文常规、操作及标题 Medium，避免到处 SemiBold。主按钮 52dp 高、12dp 圆角，辅助动作中性色、至少 48dp 触控范围，图标使用同一套细线矢量。纸色表面及暖灰细线统一，消除默认灰绿弹窗和桃色大胶囊。仍跟随系统字体缩放，不缩小可访问触控区。

首页：减小品牌区，保留两行功能标题，图形与内容区域对齐。草稿首页使用宽幅、限定高度的实际图片首段预览代替把全长图压成细条；带单行保存状态与尺寸，整个卡片可继续编辑。卡片高度适应可用区域，长内容可滚动，底部主动作仍可达。

预览和裁剪：图片为主体；统一轻量工具栏、保存状态、底部细线工具条。裁剪/分享使用图标加文字的轻量按钮，保存使用一致主按钮。保留四角触控、滚动、全图、局部撤销/重做及取消不提交。

帮助和准备：清楚但安静的分组标题，紧凑分段模式选择，编号步骤；折叠项使用箭头，厂商路径与高级排障继续按需展开。首次准备主动作与手动兜底有清晰层级。

覆盖确认：暖纸弹窗，20sp 标题、14sp 说明；纵向完整动作区，保存主按钮、放弃次按钮、取消文字，避免任何语言下按钮挤成不规则两行。

悬浮：统一纸色、线条、圆角和字重，开始/结束保持明确；路线、触摸规则和计数逻辑不改。无障碍及投屏只在需要时临时启用，验收后恢复。

验收以真实 Android 渲染截图为准：浅色/深色、英文大字号、空首页/草稿首页、预览/裁剪/查看菜单、帮助/准备/覆盖确认；关键按钮不遮挡、长图预览不变细条、返回及取消不丢失草稿。先备份实际调试包草稿，自动化验证后恢复。正式包不动。
