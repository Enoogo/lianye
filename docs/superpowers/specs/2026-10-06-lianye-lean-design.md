# 连页：简洁够用的原型修订

## 用户约束与独立评审

用户明确取消隐私遮盖，要求按 Unix 哲学保持简单够用，恢复此前安卓厂商帮助，并让独立 agent 评估设计感与体验平衡。三位 agent 独立查看同一份 V1 截图和代码，互不读取报告、互不讨论；结果见 `design/brand/lianye/prototype/review/independent-{visual,ux,minimal}-audit.md`。原评审画面保留为 `review/overview-v1.png`，完整原型快照为 `review/prototype-v1.html`。

共同结论：名称、Logo、配色成立；主要负担来自遮盖编辑、重复能力说明、保存/分享后的二次确认，以及厂商帮助遗漏。视觉 agent 建议保留首页大标题和图形，UX agent 强调长图定位与可访问替代不能消失；精简 agent 要求高级排障不进入普通流程。采纳这些边界，修订可审阅原型，暂不修改 Android 实现。

## 收敛后的设计

- **核心任务**：截取 → 检查/可选裁剪 → 保存或系统分享。只有一份当前草稿。
- **首页**：保留品牌、两行标题、一句功能说明、长图示意、一个主动作和可读的帮助入口。删除眉题、示意旁文字、重复隐私脚注。草稿首页使用真实缩略图和单行状态，不重复宣传句。
- **首次准备**：说明无障碍用途及本机处理一次；只显示当前机型的路径和「前往设置」。授权仍由系统确认。开启后返回连页时延续此前的任务，不再要求重复点「去截图」。Android 10 仅请求仍缺少的捕获能力。
- **截取中**：屏数与「结束」合在一个可拖动控制中，不另外覆盖一条状态栏。
- **结果**：标题「长图」、单行保存状态、尽量宽的图片；默认只有裁剪、保存、带文字的分享。缩放及顶部/底部定位收进「查看」菜单，避免常驻胶囊挡住原图。
- **裁剪**：默认按手机宽度显示、纵向滚动；可切换全图定位。保留四角拖动和方向键操作、局部撤销/重做、还原。删除百分比滑条；取消不提交，应用才更新草稿。
- **保存/分享反馈**：按钮显示保存进度，行内显示成功或失败；不弹成功确认。分享使用系统样式面板模拟，返回后保留草稿，不声称已发送，也不自动保存至相册。
- **草稿保护**：普通返回都保留草稿；只在新截图替换未保存草稿时询问一次。「保存并新建」成功后直接开始下一步，失败则留在当前图；已保存版本撤销回来不再错误地要求重存。
- **设置/帮助**：空闲停用直接执行并保留草稿；三步操作说明、一条本机路径和受限设置帮助。应用信息直达仍在；电池设置和 ADB 放进默认折叠的高级排障。

## 厂商帮助范围

复用项目已有分组：小米/Redmi/Black Shark，OPPO/一加/realme，vivo/iQOO，华为/荣耀，三星，以及原生安卓回退。原型用画面外的「模拟手机」验证分支；产品内不要求用户先选择品牌，实际应用仍以 `DeviceVendorDetector` 自动识别。

这些路径来自现有中文资源，并非所有最新系统版本已实机核实。首次页从「无障碍」显示短路径，帮助中才展开完整路径和「入口名称随系统版本变化」。不把标准设置 Intent 的定位参数当成厂商通用的直达保证。

## 验收

检查删除遮盖与相关样例号码；六类路径与原有资源一致；保存与分享无二次成功确认；返回保留草稿；替换仅保护未保存内容；裁剪内容可读且取消、局部历史有效；保存版本能恢复；窄屏、深色、键盘、宿主状态回传和重新挂载正常。所有授权、系统入口、截图、导出及高级排障动作仍为模拟。

V2 已完成三方独立复核。视觉评审认为首页气质与任务页图片层级均可用于评审；精简评审确认六组路径一致，并提出手动结束说明和复制命令两处收尾，现已采纳。交互评审发现保存异步回调可能作用于新草稿：实际浏览器重现后，增加保存期间禁用新建和草稿身份绑定；回归验证与独立复核均通过，未增加确认弹窗。

新鲜验证：15 个模型/厂商测试，98 项浏览器流程与响应式检查，7 项宿主检查，0 JS 异常；另有保存竞态回归。截图总览已重制并实际查看。证据与运行方式见 `design/brand/lianye/prototype/README.md`。
