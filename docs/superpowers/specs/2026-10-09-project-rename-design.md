## 命名

- 中文：连页；英文：Lianye。
- GitHub：`gxwane/lianye`；Gradle root：`Lianye`。物理目录暂保留 `E:\Documents\scroll-loom`，用户明确后续自行改为 `E:\Documents\lianye`。

- 发布产物：`Lianye-v版本号.apk`；本地签名文件：`lianye-release.jks`、`lianye-fdroid.jks`。保留密钥材料，修改文件引用，不重建证书。

## 范围与执行顺序

先完成源码、资源、测试、混淆规则、生成脚本、发布工作流、F-Droid 元数据及现行文档，再进行构建和实机验证，最后改 GitHub 仓库。应用更新入口、元数据来源和 Pages 链接跟随新仓库名称；工作流从 repository owner/name 推导 Pages URL，避免再次硬编码旧路径。

用户在目录移动遇到 Windows 占用后明确要求延后；本地物理目录只影响存放路径，不影响 Gradle 工程名称、应用身份及安装包。停止尝试移动或释放占用，不将其列为本次完成的阻塞项。以后移动时再同步本地签名路径。

现行品牌说明应反映已实现的取景框/长页标记、暖白/墨黑/陶橙与统一悬浮交互。历史验收及探索记录保留原文，新的迁移记录提供当前身份；不改写过去运行过的包名与命令。生成的构建缓存、历史设备日志及图片不参与批量替换。

用户要求不备份。新包无需旧数据迁移；不把该要求解释为删除手机上其他已有安装的数据。实机只安装新测试包并清理本次测试辅助包及临时文件。临时权限测试后关闭本次新增权限，恢复原有其他服务状态。

不提交、不推送代码、不创建发布；仓库改名本身在此次授权范围。Windows 根目录移动必须先验证源与目标绝对路径，确认目标不存在，并按文件系统权限执行。
