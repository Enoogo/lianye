# 连页：首页视觉精修

用户认可现有操作逻辑，并同意本轮评审提出的首页视觉调整：减轻标题，重做连续长图插画，收紧留白，弱化模式切换的容器，统一 Logo、线条和深色显示。

## 视觉结构

- 品牌与帮助仍在顶部。品牌图形保持原有几何形状，用当前主题的墨色绘制取景角、橘色绘制长图轮廓，移除深色主题下的浅色底块。文字与图形做光学对齐，顶部和内容使用同一最大宽度。
- 空首页将标题、一句功能说明和插画居中组成完整的一组。中文标题保留原文，取消强制换行，使用 24sp / 32sp；说明 14sp / 21sp，收紧为“自动滚动，拼成长图。”及“自己滑动，拼成长图。”。普通手机宽度显示一行中文标题，大字体及窄屏使用均衡断行。
- 内容在可用区域内居中分配留白，超出高度时可滚动，底部操作区始终可达。草稿首页保留标题和真实缩略图的既有行为，减少装饰对实际内容的干扰。
- 插画由上下两段对齐的页面构成，正文位置连续，用短橘色连接标记跨过两段之间的边界。去掉横跨整页的裁剪状横线和错位纸片。图形约 160dp 宽、220–240dp 高；少量分组正文线和内容块表示真实页面结构，不附加解释文字。
- 模式切换维持自动 / 手动两个可见入口，使用文字、颜色和短下划线表示选择，移除厚底色和白色选中块。触控范围仍至少 48dp，读屏角色及 selected 状态保持明确。
- 主按钮保持既有动作、标签、52dp 最小高度和墨色填充，是下方最明确的操作。

## 实现边界与验收

本轮修改首页布局、装饰插画、顶部主题绘制和模式控件外观。捕获、权限、草稿保护、悬浮球和恢复逻辑沿用现有实现。

使用原生 Compose / Canvas 实现图形，不引入图片生成、网络依赖或字体包。查看实机自动 / 手动空首页、真实草稿首页、中文深色、英文及中文大字体窄屏。验证模式切换和主动作、草稿保存后回到首页、帮助入口和截图准备仍可用。测试前备份当前调试包数据，结束后按文件哈希核对恢复，保留正式包和相册。
