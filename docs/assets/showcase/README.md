# 连页公开演示素材

2026-10-09 采集自正式版 **v0.1.0 / org.lianye**，Huawei STK-AL00 / Android 10。首页、手动截图和裁剪画面来自手机，不使用历史原型或模拟产品界面。

- `home.png`、`capture.png`、`crop.png`：真实界面，去除系统状态栏并等比例缩小到 540 × 1134。
- `demo.mp4`、`demo.gif`：真实手动模式操作，包含开始、滑动、结束、裁剪、保存；省略等待和部分重复滑动，并加速播放。MP4 无音频，GIF 为压缩预览；播放时长不代表实际捕获速度。
- `result.png`：上述操作保存的实际 PNG，1080 × 9275；已在应用里裁掉顶部状态栏，内容未另行修改。
- `social-card.png`：1200 × 630 链接分享封面，从 `website/social-card.svg` 渲染，使用现行品牌色。

示例文章“一页周末”与内嵌 SVG 插画为本项目原创内容，不含个人聊天、账号或第三方文章。采集后恢复本次权限变动，清理本次相册演示图，保留原有文件。

原始录屏与验证证据保存在忽略的 `build/showcase-seo/`。官网和根 README 共用本目录；后续版本修改实际操作界面后应重新录制，并更新此说明及网页中的演示版本。
