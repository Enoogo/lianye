# 连页设计令牌

## 品牌颜色

| 角色 | 色值 |
| --- | --- |
| 暖白纸底 | #F7F4EE |
| 墨黑取景框、正文 | #252B2A |
| 陶橙长页 | #DB653D |
| 深色页面背景 | #1D2422 |
| 深色长页强调 | #F4A584 |

普通桌面图标采用暖白底、墨黑取景框、陶橙长页。应用内和启动标记在深色背景上使用暖白取景框与浅陶橙长页。主题单色图标提供相同光学几何的透明单色层。

`tokens.json` 的 `brand` 字段通过 `tool/sync_brand_assets.py` 同步到 Kotlin、Android 和现行 SVG，修改后运行同步与 `--check`。历史探索图片不属于当前令牌输入。

## 界面角色

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | #F7F4EE | #1D2422 |
| 正文 / 主按钮 | #252B2A | #F7F4EE |
| 主色容器 | #EFEBE4 | #303B35 |
| 辅助强调文字 | #A54023 | #F4A584 |
| 强调容器 | #F7E4D9 | #573225 |
| 卡片 | #FFFFFF | #29322F |
| 辅助正文 | #6C6D68 | #ADB7B0 |
| 边界 | #E0DDD6 | #45514B |
| 错误文字 | #B33B36 | #FFB4AA |

品牌陶橙用于图形。浅色页面的小号强调文字使用更深的 #A54023，避免把装饰色直接当作小字颜色。

## 排版与间距

系统字体。常用标题 24/33sp、20/28sp 和 18/26sp；正文 15/23sp，辅助正文 14/21sp，注释 12/18sp。具体组件选择对应的 Material Typography 层级，字体随系统设置缩放，不用固定高度裁掉文字。

间距为 4、8、12、16、20、24、32dp。帮助内容常用边距 24dp，首页按现行布局使用 20dp。内容最大宽度 560dp；触摸目标至少 48dp。主题圆角层级为 6、10、12、18、20dp，组件可按自身功能覆盖。

## 图形

品牌为四个有限取景角和一张越过范围下界的连续长页；主版线重 5.8，小尺寸光学版线重 7。自适应图标使用透明 108×108 前景，保留既有安全范围和居中位置。操作图标采用独立的 24dp 线条体系，不混用品牌标记。
